# Non-goals

AgentRC deliberately does not define:

1. a runtime;
2. a sandboxing implementation;
3. a cloud platform;
4. a model API;
5. an agent framework;
6. a full workflow language inside Agentfile;
7. a proprietary registry;
8. a replacement for MCP, A2A, Cedar, OCI, OpenTelemetry, Sigstore, SLSA, Docker, Kubernetes, gVisor, or Firecracker.

The specification should stay narrow enough that many runtimes and clouds can consume it without treating it as a competitor.
